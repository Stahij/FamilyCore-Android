# FamilyCore Android — MVP 0.3.0

FamilyCore — локальный Android-прототип семейного цифрового центра.

## Что можно проверить в версии 0.3.0
- Домашний экран с обзором семейных дел и быстрыми переходами.
- Локальные задачи: добавление, выполнение и удаление.
- Локальный календарь: добавление и удаление событий (пока без системных напоминаний).
- Кухня: список покупок, домашние запасы и сроки годности, стартовая подборка рецептов.
- Личные заметки: создание, поиск и удаление.
- Три цветовые темы: лаванда, шалфей и океан.
- Сохранение перечисленных данных на устройстве между запусками.

## Что пока НЕ реализовано
- Аккаунты, семейная группа, чат и синхронизация между устройствами.
- Настоящий ИИ-помощник.
- Дополнительное шифрование локальных записей.
- Автоматические уведомления, импорт системного календаря и облачная резервная копия.
- Автоматическое меню, расчёт ингредиентов и автоматическое определение срока годности.

Данные MVP хранятся в SharedPreferences без дополнительного шифрования. Не сохраняйте пароли, платёжные данные и другие секреты.

## Сборка тестового APK
GitHub Actions автоматически запускает unit-тесты, собирает debug APK и release AAB. Откройте вкладку Actions, выберите последний успешный запуск и скачайте артефакт `FamilyCore-0.3.0-debug-apk`. Распакуйте ZIP и установите APK на Android.

## Публикация в Google Play
Проект настроен на Android API 36. Для загрузки в Play Console нужен подписанный release AAB и завершённые настройки Play Console. Подпись можно настроить через переменные окружения:
- `FAMILYCORE_UPLOAD_STORE_FILE`
- `FAMILYCORE_UPLOAD_STORE_PASSWORD`
- `FAMILYCORE_UPLOAD_KEY_ALIAS`
- `FAMILYCORE_UPLOAD_KEY_PASSWORD`

Не добавляйте файл keystore или пароли в репозиторий. Храните их в защищённых GitHub Actions secrets. Без настройки ключа подписи release AAB нельзя загружать в Play Console.

Для новых личных аккаунтов Google Play, созданных после 13 ноября 2023 года, перед доступом к production требуется закрытое тестирование минимум с 12 тестировщиками, которые непрерывно участвуют не менее 14 дней. Условия зависят от типа аккаунта и актуальных правил Play Console.
