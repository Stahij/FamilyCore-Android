# FamilyCore Android — MVP 0.8.0

FamilyCore — локальный Android-прототип семейного цифрового центра.

## Что нового в 0.8.0
- Добавлена настройка языка интерфейса: русский, английский, китайский (упрощённый), испанский и хинди. Выбор сохраняется локально на устройстве.
- Добавлена персональная тема **Obsidian Gold**: тёмные поверхности, золотые акценты и повышенный контраст. Она доступна в настройках приложения и не требует отдельного аккаунта.
- Версия приложения обновлена синхронно в Gradle, заголовке приложения и названиях артефактов сборки.

## Что уже доступно в прототипе
- Домашний экран с пятью интерактивными зонами: кухня, гостиная, детская, кабинет и прихожая.
- Локальные задачи: добавление, выполнение и удаление.
- Локальный календарь: добавление и удаление событий (пока без системных напоминаний).
- Кухня: список покупок, домашние запасы и стартовая подборка рецептов.
- Личные заметки: создание, поиск и удаление.
- Сохранение перечисленных данных на устройстве между запусками.

## Что пока НЕ реализовано
- Аккаунты, семейная группа, настоящий чат и синхронизация между устройствами.
- Настоящий ИИ-помощник.
- Дополнительное шифрование локальных записей.
- Автоматические уведомления, импорт системного календаря и облачная резервная копия.
- Полная профессиональная локализация каждого динамического сообщения и пользовательских данных. Переведены основные навигационные элементы и часто используемые подписи; отдельные динамические тексты могут оставаться на русском.

Данные MVP хранятся в SharedPreferences без дополнительного шифрования. Не сохраняйте пароли, платёжные данные и другие секреты.

## Сборка тестового APK
GitHub Actions запускает unit-тесты, собирает debug APK и release AAB. Откройте вкладку Actions, выберите последний успешный запуск и скачайте артефакт `FamilyCore-0.8.0-debug-apk`. Артефакт представляет собой ZIP: распакуйте его и установите APK на Android.

## Подпись и публикация
Сборка проверяет подпись APK и сохраняет диагностический отчёт. Для загрузки в Play Console нужен подписанный release AAB и завершённые настройки Play Console. Подпись релизной сборки можно настроить через переменные окружения:
- `FAMILYCORE_UPLOAD_STORE_FILE`
- `FAMILYCORE_UPLOAD_STORE_PASSWORD`
- `FAMILYCORE_UPLOAD_KEY_ALIAS`
- `FAMILYCORE_UPLOAD_KEY_PASSWORD`

Не добавляйте keystore или пароли в репозиторий. Храните их в защищённых GitHub Actions secrets. Без настройки ключа подписи release AAB нельзя загружать в Play Console.
