# FamilyCore Android MVP

Минимальный нативный Android-прототип для первичного тестирования.

## Уже заложено
- Kotlin + Jetpack Compose.
- Локальные заметки: создание, поиск, изменение через форму, удаление.
- Сохранение между перезапусками.
- Вкладка ИИ с явной заглушкой до интеграции движка.
- GitHub Actions: unit test task и сборка debug APK.

## Пока не реализовано
- Реальный локальный ИИ, llama.cpp и скачивание GGUF.
- Шифрование хранилища.
- P2P, сопряжение устройств и синхронизация.
- Резервное копирование и UI-тесты на реальном устройстве.

Важно: заметки пока хранятся в SharedPreferences без дополнительного шифрования. Не сохраняйте секреты и особо чувствительные данные.

## Как получить APK
1. Откройте вкладку Actions и разрешите workflows, если GitHub попросит.
2. Запустите `Build Android APK` через Run workflow или отправьте commit в `main`.
3. Откройте запуск и скачайте артефакт `FamilyCore-debug-apk`.
4. Распакуйте артефакт и установите `app-debug.apk` на Android. При необходимости разрешите установку из выбранного источника.

Если workflow завершился ошибкой, сохраните лог упавшего шага: по нему нужно исправлять сборку. Успех не считается подтверждённым до успешного выполнения GitHub Actions и установки APK на устройстве.

## Параметры
- Минимум Android 8.0 (API 26).
- SDK 35, JDK 17, Gradle 8.9, Android Gradle Plugin 8.7.3.
- Debug APK предназначен для тестирования, не для публикации в магазине.

## Следующий этап: локальная модель
Кандидат: Qwen2.5-1.5B-Instruct GGUF Q4_K_M. Модель скачивается отдельно от APK. Перед интеграцией необходимо закрепить версию llama.cpp, проверить ABI/память на устройстве, проверять источник и SHA-256 файла, показывать лицензию и не скачивать модель без явного действия пользователя.

Страница модели: https://huggingface.co/Qwen/Qwen2.5-1.5B-Instruct-GGUF
